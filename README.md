# Neovim Configuration

Personal Neovim configuration with LSP, completion, and modern plugins.

## Requirements

- Neovim >= 0.11
- Git
- [ripgrep](https://github.com/BurntSushi/ripgrep)
- [fd](https://github.com/sharkdp/fd)
- A [Nerd Font](https://www.nerdfonts.com/)
- Node.js (for LSP servers)

## Installation

### Linux / macOS

```sh
git clone https://github.com/renzynx/nvim.git ~/.config/nvim
nvim
```

### Windows (PowerShell)

```powershell
git clone https://github.com/renzynx/nvim.git $env:LOCALAPPDATA\nvim
nvim
```

Plugins will be installed automatically on first launch.
